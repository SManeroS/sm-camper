# SM Camper 0.1
El camino es parte del viaje.

Descomprimir. Para una prueba inicial en ordenador, abrir index.html en el navegador. Para instalación PWA y caché offline, publicar todos los archivos juntos en un alojamiento HTTPS (por ejemplo GitHub Pages). El almacenamiento es local al navegador y origen; exportar antes de cambiar de dirección o dispositivo. No hay sincronización, cálculo automático de rutas, búsqueda de lugares ni IA. Las etapas y distancias son manuales. La preferencia de paseos se registra, pero aún no existe un motor de recomendaciones.
